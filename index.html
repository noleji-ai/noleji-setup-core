BEFORE YOU START

시작 전에 확인할 내용

전체 Operator를 공개한 것인가요?

설정 계획과 관리 지침 파일의 업데이트·복원 코어만 공개했습니다. 일반 업무 실행, 호스팅 서비스와 사무실 자료는 포함하지 않습니다.

내 컴퓨터 설정을 바꾸나요?

제공한 demo.py는 임시 홈에서 실행한 뒤 정리합니다. 원시 설정 메서드를 실제 홈으로 실행하면 변경이 발생할 수 있습니다.

자동으로 업데이트를 가져오나요?

공개판에는 기본 원격 업데이트 주소가 없습니다. 실제 연동에는 검토한 자료 공급 방법과 별도 권한 설정이 필요합니다.

무료로 사용할 수 있나요?

코드는 MIT로 공개합니다. 직접 사용하는 모델 계정, 제공자 호출 비용과 호스팅은 별도입니다. OpenAI와 독립적으로 운영하며 공식 추천이나 무료 사용량을 보장하지 않습니다.
