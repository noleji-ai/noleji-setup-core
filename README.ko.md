# AI 도구 설정을 검토하고 이전 상태로 복원하기

Noleji Setup Core는 AI 도구의 관리 지침 파일을 적용하기 전에 변경 계획을 확인하고, 이전 관리 버전을 복원하는 Python 코드입니다. Noleji Start와 Operator에서 설정·업데이트에 필요한 부분만 분리했습니다. 전체 서비스나 일반 업무 실행 기능은 포함하지 않습니다.

## 내 설정을 건드리지 않고 확인하기

Python 3.11 이상에서 `python3 demo.py`를 실행하세요. 임시 폴더 안에서 계획·적용·업데이트·복원과 사용자 수정 보호를 확인한 뒤 폴더를 정리합니다. 이 예제는 네트워크·모델을 호출하거나 실제 사용자 홈을 바꾸지 않습니다.

테스트 명령은 `python3 -m unittest discover -s tests -p 'test_*.py' -v`입니다. [영문 안내](README.md)와 [검증 범위](VERIFICATION.md)를 함께 보세요.

## 실제 설정 변경 전 확인할 점

공개판에는 기본 원격 업데이트 주소가 없습니다. 실제 연동은 검토한 자료 공급 방법과 권한을 별도로 정해야 합니다. 원시 설정 메서드를 직접 실행하면 지정한 홈의 파일과 도구 상태가 바뀔 수 있습니다. 테스트 통과는 실제 로그인·다른 Mac 설치·서비스 보안을 증명하지 않습니다.

MIT로 공개하며 자체 호스팅이나 실제 모델 비용은 별도입니다. 외부 사용자·학교 도입·토큰 절감·OpenAI 선정은 아직 확인되지 않았습니다. [소개페이지](https://noleji-ai.github.io/noleji-setup-core/)의 브라우저 체험은 설명용 예시이며 Python 실행을 대신하지 않습니다.
